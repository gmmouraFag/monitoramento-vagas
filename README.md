# Sistema de Detecção de Vagas de Estacionamento

Sistema de visão computacional para detectar vagas de estacionamento livres e ocupadas em tempo real.

## Descrição

Este projeto utiliza OpenCV e técnicas de processamento de imagem para:
- Marcar manualmente as posições das vagas de estacionamento
- Detectar automaticamente se cada vaga está livre ou ocupada
- Exibir em tempo real o status de cada vaga
- Contar quantas vagas estão disponíveis
